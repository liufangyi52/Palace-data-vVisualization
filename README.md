# Palace Vista
中华宫殿文明数字孪生与数据可视化展示系统。项目以中国古代宫殿为主题，融合 AI 智能与数据可视化技术，结合 Vue 前端交互、ECharts 数据图表、Three.js 3D 可视化和 Express 后端接口，全方位展示宫殿概览、历史时间线、建筑规制、工艺材料、成就影响、宫殿对比和地图分布等内容。


## 项目功能

- 宫殿首页展示与轮播介绍（涵盖汉、隋、唐、宋、元、明、清六大朝代的代表性宫殿）
- 宫殿详情、朝代筛选与搜索
- 7 大可视化模块：数据总览、建筑规制、工艺材料、成就影响、宫殿对比、历史时间线、数据可视化
- 3D 交互展示：基于 Three.js 的宫殿三维可视化
- 宫殿地图：基于地理坐标的宫殿分布地图
- 沉浸式 UI：深色主题 + 金色点缀的中国古典风格界面设计
- 粒子动效：首页粒子背景动画，增强视觉沉浸感
- 后端 REST API 与健康检查接口


## 技术栈

- 前端：Vue 3、Vue Router、Vite
- 可视化：ECharts、Three.js
- 请求：Axios
- 后端：Node.js、Express
- 数据库：MySQL
  
### 环境要求
- Node.js >= 20.0.0
- MySQL >= 8.0
