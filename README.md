# Palace Vista

中华宫殿文明数字孪生与数据可视化展示系统。项目以中国古代宫殿为主题，结合 Vue 前端交互、ECharts 数据图表、Three.js 可视化和 Express 后端接口，展示宫殿概览、历史时间线、建筑规制、工艺材料、成就影响、宫殿对比和地图分布等内容。

## 项目功能

- 宫殿首页展示与轮播介绍
- 宫殿详情、朝代筛选与搜索
- 建筑面积、房屋数量、年代等数据可视化
- 工艺材料与历史时间线展示
- 宫殿对比分析
- 宫殿地图与交互式展示
- 后端 REST API 与健康检查接口

## 技术栈

- 前端：Vue 3、Vue Router、Vite
- 可视化：ECharts、Three.js
- 请求：Axios
- 后端：Node.js、Express、CORS
- 日志：Winston
- 数据库：MySQL
